Unidad 8. Next.js App Router: rutas, Server/Client Components y datos

Next.js con App Router introduce un modelo donde el servidor es el entorno por defecto para componentes, datos y composición de rutas. Entender la diferencia entre Server y Client Components, el sistema de archivos como enrutador, los layouts y las estrategias de carga/caché permite construir aplicaciones rápidas, seguras y con buena experiencia de usuario. Esta unidad practica decisiones de arquitectura en App Router, manejo de estados de carga/error y obtención de datos.

Ejercicio 12. Elegir avanzado: decisiones y trade-offs

Selecciona la opción más adecuada.

  1. Requisito ambiguo: (definir contrato y validar / asumir / implementar sin acordar).
  2. Fallo transitorio de dependencia: (retry con backoff y límite / reintento infinito / ignorar error).
  3. Cambio incompatible: (versionar/migrar / romper silenciosamente / no avisar).
  4. Acceso a datos sensibles: (mínimo privilegio y controles / acceso amplio / exponer en logs).
  5. Degradación de rendimiento: (medir y optimizar cuello / optimizar a ciegas / ignorar).
  6. Entregas frecuentes: (CI con gates / deploy manual sin pruebas / saltar revisión).
