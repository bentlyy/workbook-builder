Unidad 7. React: efectos, hooks y rendimiento

Los hooks permiten encapsular lógica con estado y efectos secundarios en componentes funcionales, pero un uso incorrecto genera bugs difíciles de rastrear y problemas de rendimiento. Comprender el ciclo de efectos, las dependencias, la memoización y las reglas de los hooks es fundamental en aplicaciones React 18 y Next.js. Esta unidad practica useEffect, useMemo, useCallback, hooks personalizados y estrategias para evitar renders innecesarios.

Ejercicio 1. Completar: useEffect y ciclo de efectos

Completa con el concepto correcto.

Ejemplo: Ejemplo: El array de dependencias de useEffect indica cuándo debe re-ejecutarse el efecto.
  1. useEffect se usa para sincronizar el componente con sistemas (fetch, suscripciones, timers, DOM).
  2. Un efecto que retorna una función define una que se ejecuta antes de re-ejecutar el efecto o al desmontar.
  3. Un array de dependencias vacío [] indica que el efecto se ejecuta tras el montaje.
  4. Omitir dependencias usadas dentro del efecto puede provocar valores (stale closures).
  5. Agregar objetos/funciones creadas en cada render al array puede causar ejecuciones si no se estabilizan.
  6. Los efectos se ejecutan después del y pintado, no durante la renderización pura.
