Unidad 2. TypeScript esencial: tipos, uniones y narrowing

TypeScript añade un sistema de tipos estático sobre JavaScript que ayuda a detectar errores antes de ejecutar el código y a documentar contratos entre módulos. Comprender tipos primitivos, uniones, interfaces, genéricos básicos y narrowing te permite modelar datos reales de APIs y UI con mayor seguridad. Esta unidad practica anotaciones, inferencia, refinamiento de tipos y decisiones de modelado habituales en proyectos Node.js y React.
